# Котик ждёт / 猫咪在等你

Виртуальный котёнок, который помогает бросить пить. Котик растёт с каждым трезвым днём,
грустит, если ты выпил, и его нужно кормить, мыть и убирать за ним лоток.
Интерфейс на русском и китайском (переключается в настройках).

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm run build    # готовая сборка в папке dist/
```

Папку `dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel).

## Структура

- `src/App.jsx` — логика игры
- `src/i18n.js` — все тексты (ru / zh)
- `src/stats.js` — скорость, с которой падают сытость, чистота и т.д.
- `src/components/` — котик, календарь, иконки, миска и лоток, настройки, экран знакомства
- `src/assets/` — спрайты котика (8 кадров в ряд, 240×240), фоны и награды

Прогресс сохраняется в localStorage браузера.
